**Resumen Extenso: Día 18 de septiembre de 2025**

**Objetivos del día**

* Introducir la alteración de tablas en MySQL
* Explorar las validaciones de datos y los índices en MySQL
* Comprender cómo funcionan las consultas SQL para seleccionar, ordenar y filtrar datos

**Conceptos clave**

* **Validaciones de datos**: son reglas que se establecen para asegurar que la información almacenada en una tabla sea correcta y consistente.
* **Índices**: permiten mejorar el rendimiento de las consultas SQL al proporcionar un acceso más rápido a los datos.

**Explicación didáctica**

La clase comenzó con la introducción de la alteración de tablas en MySQL. El profesor explicó que se puede agregar, modificar o eliminar columnas y restricciones a una tabla existente utilizando el comando `ALTER TABLE`. Se mostró un ejemplo de cómo agregar una validación para asegurar que el número de teléfono tenga un mínimo de 9 caracteres.

A continuación, se exploraron las validaciones de datos. El profesor explicó que se pueden establecer reglas para asegurar que la información almacenada en una tabla sea correcta y consistente. Se mostró un ejemplo de cómo agregar una validación para asegurar que el formato del correo electrónico sea válido.

Luego, se introdujeron los índices. El profesor explicó que permiten mejorar el rendimiento de las consultas SQL al proporcionar un acceso más rápido a los datos. Se mostró un ejemplo de cómo crear un índice en una tabla para mejorar la velocidad de las consultas.

**Pasos y comandos**

* `ALTER TABLE`: comando utilizado para agregar, modificar o eliminar columnas y restricciones a una tabla existente.
* `ADD CONSTRAINT`: comando utilizado para agregar una validación a una columna.
* `CREATE INDEX`: comando utilizado para crear un índice en una tabla.

**Buenas prácticas**

* Es importante establecer validaciones de datos adecuadas para asegurar la calidad de la información almacenada en las tablas.
* Los índices pueden mejorar significativamente el rendimiento de las consultas SQL, pero es importante crearlos solo cuando sea necesario.
* Es importante seguir una estructura lógica y consistente al crear tablas y establecer validaciones.

**Resumen**

En resumen, la clase del día 18 de septiembre de 2025 se centró en la alteración de tablas, las validaciones de datos y los índices en MySQL. Se mostraron ejemplos prácticos para ilustrar cómo funcionan estas características y se destacaron las buenas prácticas para utilizarlas de manera efectiva.
