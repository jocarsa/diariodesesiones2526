Objetivos:

Conceptos Clave:

* **Variables**: Son espacios de almacenamiento en la memoria donde se pueden guardar valores. En este caso, se utilizan para almacenar información sobre una película.
* **Operadores Aritméticos**: Se utilizan para realizar cálculos con números. En este ejemplo, se utiliza el operador `-` (resta) para calcular la diferencia entre dos años y el operador `/` (división) para calcular la duración de una película en horas y minutos.
* **Funciones**: Son bloques de código que realizan una tarea específica. En este caso, se utilizan funciones predefinidas del módulo `math` para realizar cálculos matemáticos.

Explicación Didáctica:

Imagina que estás trabajando en un proyecto de programación y necesitas crear un programa que gestione información sobre películas. El sistema te proporciona un ejercicio con una serie de instrucciones para resolver.

1. **Declara variables**: Primero, debes declarar variables para almacenar la información sobre la película. En este caso, se utilizan variables como `title`, `release_year`, `duration` y `rating`.
2. **Realiza operaciones aritméticas**: A continuación, debes realizar operaciones aritméticas con las variables para calcular la diferencia entre dos años y la duración de la película en horas y minutos.
3. **Imprime resultados**: Finalmente, debes imprimir los resultados en la pantalla en un formato específico.

Pasos/Comandos:

* `import math`: Importa el módulo `math` para utilizar funciones predefinidas.
* `title = "The Neverending Story"`: Declara una variable `title` con el valor `"The Neverending Story"`.
* `release_year = 1984`: Declara una variable `release_year` con el valor `1984`.
* `duration = 102`: Declara una variable `duration` con el valor `102`.
* `rating = 10`: Declara una variable `rating` con el valor `10`.
* `elapsed_time = 2025 - release_year`: Calcula la diferencia entre dos años utilizando el operador `-`.
* `hours = duration // 60`: Calcula la duración de la película en horas utilizando el operador `//`.
* `minutes = duration % 60`: Calcula la duración de la película en minutos utilizando el operador `%`.
