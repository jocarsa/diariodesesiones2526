**Conceptos Clave:**

* **Biblioteca de gráficos**: Una colección de funciones y componentes que permiten la creación de diferentes tipos de gráficas, como líneas, columnas, barras, donuts, radar, etc.
* **Legendas estáticas**: Informaciones adicionales que se muestran en las visualizaciones para proporcionar contexto y entender mejor los datos.
* **Herramientas de ayuda**: Elementos interactivos que permiten a los usuarios obtener información adicional sobre la visualización.

**Código:**

```python
# Ejemplo de código para agregar legendas estáticas
import matplotlib.pyplot as plt

# Crea un gráfico de barras

# Muestra el gráfico
plt.show()
```
